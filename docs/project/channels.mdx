# Community channels

| Channel | For |
|---|---|
| [Discord](https://discord.gg/DuRg87MvgD) | The main community: questions, contributors, roles and events |
| [X](https://x.com/OrivonBrowser) | News and releases |
| [Telegram](https://t.me/OrivonBrowser) | Support and discussion |
| [GitHub](https://github.com/OrivonBrowser) | Code, issues and releases |

## Getting help

- **Something broke in the browser:** use **Report a problem** in Orivon's menu. The form shows the
  full report before you send it.
- **A question about using Orivon:** ask in Discord or Telegram.
- **A bug in the code, or a feature idea:** open an issue on
  [GitHub](https://github.com/OrivonBrowser/orivon-mvp/issues).

## Security

Report a vulnerability privately, as
[SECURITY.md](https://github.com/OrivonBrowser/orivon-mvp/blob/main/SECURITY.md) describes, never
in a public issue or channel.

## Privacy

Questions about your data go to privacy@orivonstack.com. See
[Privacy and your data](/docs/using/privacy).
