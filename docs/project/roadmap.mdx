# Roadmap

Where Orivon is and where it is going. Nothing under *Expected next* or *Later* is a promise or has
a date. A feature is built when a real app, a person or the work itself calls for it.

## Now

- A complete desktop browser: profiles, private windows, tab groups and Chrome extensions.
- The capability broker and a Node.js layer, so apps can do what a web page cannot.
- The app loader, with hash-pinned apps that run from your disk.
- `.eth` names and `ipfs://` / `ipns://` content, verified on your machine.
- The Web3 Score, with providers you choose.
- Packages for Linux, Windows and macOS.

[Features](https://github.com/OrivonBrowser/orivon-mvp/blob/main/docs/features.md) lists everything
that works today, one line each.

## Expected next

- A native wallet is on the way.
- Signed self-update, which always waits for your "Yes, install".
- Orivon Explore as a directory of apps.
- More ported apps.

## Later

- Mobile.
- Cross-device sync.
- Stronger sandboxing of untrusted apps.
- Native desktop apps such as Bisq, rendered in a tab.
- Tor and proxy chains.
- Web3 search.

## The direction

Any Web3 codebase, from a full node to a DEX to a Tor proxy, running as a site the moment you open
its name.

## What Orivon will not do

- Put an Orivon server in the path of using it.
- Pass off a judged score as one your machine verified.
- Run native machine code for an app.

The full list, with smaller items, is in the
[roadmap on GitHub](https://github.com/OrivonBrowser/orivon-mvp/blob/main/docs/roadmap.md).
