# Quick start

Five minutes from a fresh install to a desktop app running in a tab. If Orivon is not installed yet,
start with [Download and install](/docs/start/download).

## 1. Enter Orivon

The first launch shows a welcome screen with one button, **Enter Orivon**. A short question follows
about anonymous usage statistics; choose either answer, it changes nothing else. The new-tab page
opens with a search box, a row of featured apps and your bookmarks.

## 2. Open an app by its name

Type this in the address bar and press Enter:

```text
freetube.orivonstack.eth
```

Before anything loads, Orivon proves the name. A light client on your machine checks the `.eth`
record against the Ethereum chain, and every block of the app is hashed against its content
identifier as it arrives. No server along the way is trusted to be right.

## 3. Read the question, then decide

FreeTube is a desktop app, so it needs more than a web page may have. Orivon shows one question, in
plain words, covering everything the app declared:

<Shot
  src="/img/product/consent.webp"

Choose **Allow** and the app is installed: its files are cached and pinned to the exact version you
accepted. Choose **Deny** and nothing is granted.

## 4. Use it

FreeTube now runs in the tab as its desktop version does. Next time you open the name, it starts
from your disk, even with the network unplugged.

## 5. Check what you are on

Click the shield in the address bar: the [Web3 Score](/docs/using/web3-score) panel says what your
machine verified. The **Permissions** button beside it lists every power the app holds, each with
its own switch.

## Try the others

| App | Address | What it is |
|---|---|---|
| Element | `element.orivonstack.eth` | Encrypted Matrix chat |
| The Lounge | `thelounge.orivonstack.eth` | An IRC client whose own Node.js server runs inside the tab |
| AirGap Vault | `airgapvault.orivonstack.eth` | Secret storage for offline signing |
| ASGARDEX | `asgardex.orivonstack.eth` | A THORChain wallet and cross-chain swap client |
| Orivon Explore | `explore.orivonstack.eth` | A directory of Web3 sites, each with its Web3 Score |

:::caution Early access

These apps are early-access ports. Keep funds you cannot afford to lose out of the wallets for now.

:::
